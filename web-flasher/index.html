Shabbat Countdown — CYD Flasher

Flash the ShabbatCon countdown clock firmware straight from your browser — no software to install.

Before you flash

  1. Use Chrome or Edge on a desktop computer (Web Serial isn't available in Safari, Firefox, or on most mobile browsers).
  2. Connect your CYD (Cheap Yellow Display, Sunton ESP32-2432S028R) board with a USB cable that carries data — some cables are charge-only.
  3. Click the button below, pick the board's serial port when prompted, and follow the on-screen steps.

Install firmware

Your browser doesn't support Web Serial. Please open this page in Chrome or Edge on a desktop computer instead. This page needs to be served over HTTPS (GitHub Pages is) — Web Serial is blocked on plain HTTP.

After flashing

The device boots with no Wi-Fi network configured. Tap the wrench icon in the top-right corner, choose WI-FI, and enter your network name and password on the on-screen keyboard — they're saved to that device's own storage, never baked into the firmware, so this same public build works for anyone.

From that same settings menu you can also set your ZIP code, brightness, the havdalah offset, and the device's clock.

Firmware built automatically from the CYD sketch in this project's GitHub repo — see the repo README for details.
