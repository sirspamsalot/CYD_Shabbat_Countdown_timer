Shabbat Countdown — Firmware Flasher

Flash the ShabbatCon countdown clock firmware straight from your browser — no software to install.

What the display looks like mid-week, counting down to candle-lighting

Before you flash

  1. Use Chrome or Edge on a desktop computer (Web Serial isn't available in Safari, Firefox, or on most mobile browsers).
  2. Connect your CYD (Cheap Yellow Display, Sunton ESP32-2432S028R) board with a USB cable that carries data — some cables are charge-only.
  3. Click the button below, pick the board's serial port when prompted, and follow the on-screen steps.

Install firmware

Your browser doesn't support Web Serial. Please open this page in Chrome or Edge on a desktop computer instead. This page needs to be served over HTTPS (GitHub Pages is) — Web Serial is blocked on plain HTTP.

After flashing

The device boots straight into a first-run screen offering two choices: connect to Wi-Fi (auto time sync, then set a ZIP or city) or set time + city for fully offline use (no network ever required). Wi-Fi credentials, ZIP/city, brightness, havdalah offset, and the clock are all saved to the device's own storage, never baked into the firmware — so this same public build works for anyone.

Settings → SYSTEM RESET wipes everything and returns to that first-run screen, if you ever want to start over.

Install firmware

Your browser doesn't support Web Serial. Please open this page in Chrome or Edge on a desktop computer instead. This page needs to be served over HTTPS (GitHub Pages is) — Web Serial is blocked on plain HTTP.

After flashing

The device boots straight into a first-run screen (navigated with the MENU / EXIT buttons and the rotary UP / DOWN / OK control) offering two choices: connect to Wi-Fi (a temporary hotspot you join from your phone to enter your network's name/password, then auto time sync and a ZIP/city) or set time + city for fully offline use (no network ever required). Everything is saved to the device's own storage.

Settings → SYSTEM RESET wipes everything and returns to that first-run screen, if you ever want to start over.

Firmware built automatically from the sketches in this project's GitHub repo — see the repo README for details.
